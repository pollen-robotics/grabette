Grabette BT Tool — WiFi provisioning

Provision any Grabette, Gripette or Casquette over Bluetooth Low Energy: connect to the device, authenticate with its PIN, then hand it the WiFi credentials it should join.

Chrome or Edge required. This tool relies on Web Bluetooth, which Firefox and Safari do not implement — there is no workaround on those browsers. If Connect finds nothing on Chrome, enable this flag:
